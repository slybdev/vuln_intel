Connect Git provider

Save a GitHub or GitLab account token once to use with your repositories

GitHub and GitLab credentials are encrypted in PostgreSQL and reused for repositories from that provider. GitHub requires a fine-grained personal access token with read-only Contents access. GitLab uses a personal access token with read_repository scope. Configure self-hosted GitLab hosts in VULN_REPOSITORY_HOSTS. HTTP repository URLs are supported for those hosts, but transmit credentials without encryption; use only on a trusted network.
